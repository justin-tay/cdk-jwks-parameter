# Security policy

This library generates and rotates private keys, so security reports are
taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/justin-tay/cdk-jwks-parameter/security/advisories/new),
not in a public issue. Include the affected version, how to reproduce the
problem and its impact.

You can expect an acknowledgement within a week. Fixes are released as a new
version and disclosed in a GitHub security advisory.

## Supported versions

Only the latest release receives security fixes.
